# Standard marine-region source

The **Standard Marine Region** selector uses the **IHO Sea Areas, version 3 (2018)** maintained by the Flanders Marine Institute (VLIZ) through Marine Regions.

The software does **not** redistribute the IHO Sea Areas Shapefile. It retrieves the small catalog of region names/MRGIDs and, when a user selects a region, requests only that feature's geometry from the official Marine Regions WFS service.

## Citation

Flanders Marine Institute (2018). *IHO Sea Areas, version 3*. Marine Regions. https://doi.org/10.14284/323
