\# Changelog



All notable changes to the GODAS Regional Data Tool are documented in this file.



\## \[2.5.10] — 2026-09-23



\### Release



\* Finalized the v2.5.10 public release baseline for the GODAS Regional Data Tool.

\* Consolidated the graphical user interface refinements completed for the release.

\* Improved the presentation of the main application in maximized startup mode.

\* Refined sidebar button sizing and text wrapping for long section names.

\* Finalized the Downloading Data and Spatial Visualization layouts.

\* Preserved the interactive map workflow for rectangular region selection and transfer of selected coordinates to the Numeric Bounding Box controls.

\* Finalized map interaction behavior including mouse-wheel zoom, left-drag panning, and WGS84 longitude/latitude coordinate readout.

\* Finalized the branded startup splash and console-free Windows launch workflow.

\* Maintained the release safeguards for native-grid processing, explicit temporal completeness, unit conversion, provenance reporting, and validation scope.

\* Prepared the software package for repository distribution and subsequent DOI registration.



\## Versioning



The software follows a simple `v2.x` release scheme. The version history is maintained through tagged repository releases.
